# Diretrizes para agentes

## Pull Requests

- Escrever Pull Requests estruturadas usando o método STAR:
  - **Situação:** contextualizar o problema ou a necessidade.
  - **Tarefa:** descrever o objetivo e o escopo da mudança.
  - **Ação:** explicar as alterações realizadas e as principais decisões técnicas.
  - **Resultado:** apresentar o impacto esperado ou observado e as evidências de validação.
